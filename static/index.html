Справочное руководство zero-copy-agent

          
Практические инструкции по настройке оркестрации, IDE, локальных моделей и безопасности

        

        

          
        

      


      

        
        

          

            

              
              
1. Как настроить оркестрацию под свои задачи

            

            
          

          

            Оркестратор работает по принципу закрытого конвейера (DAG). Вы можете гибко переназначать модели для каждой роли:
          

          
    
            
  • Архитектор (Gemini 4 Neon / Claude): Создает пошаговый план решения (Blueprint) и спецификацию без написания тяжелого кода.
    • 
            
  • Исполнитель (Локальная Qwen / Облако): Генерирует чистый код строго по утвержденному плану.
    • 
            
  • Local Hard Gate (Автопроверка): Локально компилирует код и прогоняет тесты (python -m py_compile, pytest). Если проверка падает, код не уходит наружу, а отправляется на исправление.
    • 
            
  • Аудитор: Финальная сверка архитектуры с исходным запросом.
    •

3. Подключение IDE и как работает кнопка «Откатить»

          

          

            Вкладка «Интеграции IDE» настраивает ваши редакторы в 1 клик:
          

          
    
            
  • VS Code + Continue: Создает или дополняет ~/.continue/config.yaml, подключая локальный шлюз http://127.0.0.1:8000/v1.
    • 
            
  • Cursor, Windsurf, Antigravity: Подключают нативный сервер MCP по адресу http://127.0.0.1:8000/sse.
    • 
            
  • Безопасный откат: Перед каждым изменением создается снимок в ~/.zero-copy-agent/backups/. Нажатие на кнопку «Откатить» гарантированно убирает добавленные модели zero-copy и возвращает редактор в исходное состояние.
    • 
          

        


        
        

          

            
            
4. DLP и IP-Щит: защита ваших данных

          

          

            Перед тем как запрос передается в модель, движок на лету заменяет пароли, токены, ключи доступа и приватные IP-адреса на обратимые плейсхолдеры в оперативной памяти (RAM). В ответе модели эти значения бесшовно восстанавливаются. Облачные провайдеры никогда не видят ваши реальные секреты.
          

        


        
        

          

            
            
5. Полное удаление ПО с компьютера

          

          

            Если вы захотите удалить zero-copy-agent, вам не нужно вручную чистить конфиги. Нажмите кнопку «Удалить ПО с ПК» — программа автоматически восстановит чистые файлы всех ваших IDE, сотрет служебные бэкапы и закроется.
