# 🗺️ Roadmap — Zero-Copy Agent

Публичный план развития проекта. Приоритеты могут меняться в зависимости от фидбека сообщества.

## ✅ Уже работает (v1.0)
- **Гибридный шлюз:** OpenAI-совместимый API (`/v1/chat/completions`, стриминг, tool-calling) и MCP-сервер (`/mcp`, `/sse`).
- **Локальный DLP-щит:** автоматическая маскировка API-ключей, паролей, строк подключения и приватных IP (`192.168.*`, `10.*`) до отправки в облако.
- **Сжатие контекста:** BPE-компрессор для сокращения расхода токенов и подсчёт реальной экономии.
- **Каскады моделей:** режим `cascade:architect` (сильная модель планирует ➔ быстрая или локальная Ollama пишет код) с подписью отвечающей модели.
- **Подключение IDE в 1 клик:** автонастройка VS Code (Continue), Cursor, Windsurf, Antigravity + CLI (`zca integrate`) с автоматическими бэкапами и откатом.
- **Самообслуживание конфигов:** автовалидация и исправление `config.yaml` / `subscriptions.yaml` (`Config Healer`) и отображение только активных моделей.

## 🔧 В работе
- **Замкнутый цикл аудита в оркестраторе:** локальный синтаксический/тестовый гейт + проверка `git diff` Архитектором с автоматическим возвратом на доработку.
- **Десктопное приложение (Tauri v2):** лёгкий клиент с системным треем и автообновлением.
- **Расширенный Web UI:** живая лента шагов каскада, песочница для проверки DLP-правил и управление пулом аккаунтов.

## 💡 В планах
- **Умная балансировка квот:** автоматический failover между несколькими ключами/провайдерами при `429 Rate Limit` без потери контекста.
- **Air-Gapped режим:** принудительная маршрутизация чувствительных проектов строго на локальные модели (Ollama / vLLM) с блокировкой внешнего трафика.
- **Zero-Knowledge Context Slicing:** отправка в облако только изолированных интерфейсов без раскрытия полной архитектуры репозитория.
- **Система плагинов:** открытый интерфейс для подключения сторонних провайдеров и кастомных правил DLP.
