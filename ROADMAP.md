# 🗺️ Roadmap — Zero-Copy Agent

Публичный план развития проекта. Приоритеты могут меняться в зависимости от фидбека сообщества.

## ✅ Уже работает (v1.6.0)
- **Гибридный шлюз:** OpenAI-совместимый API (`/v1/chat/completions`, стриминг, tool-calling) и MCP-сервер (`/mcp`, `/sse`).
- **Целевой Diff-аудит (±25 строк контекста):** повторный аудит только затронутых файлов с автоматическим циклом доработки локальной Ollama (`qwen2.5-coder:14b`).
- **Расширенный локальный Hard Gate:** проверка синтаксиса Python (`py_compile`), JavaScript (`node --check`), скобок PowerShell (`.ps1`) и тестов `pytest` с нулевым расходом токенов.
- **Строгий аудит Архитектора:** обязательный JSON-вердикт, автоматический REJECT на неструктурированные ответы без пропуска непроверенного кода.
- **Локальный DLP-щит:** автоматическая маскировка API-ключей, паролей, строк подключения и приватных IP до отправки в сеть, с безопасным восстановлением без поломки синтаксиса.
- **Стабильные веб-сессии:** поддержка Gemini, ChatGPT, Claude, DeepSeek, Qwen, Grok с умным ожиданием ответов (TTFT + стабилизация текста), fail-fast при капче и фоновым keepalive.
- **Неблокирующая авторизация:** автоматическое сохранение профилей браузера при появлении формы ввода или закрытии окна (до 300с ожидания).
- **Честная экономика токенов:** подсчёт 100% экономии для локальной GPU и веб-сессий, расчёт экономии по сжатым токенам для платных API-ключей.
- **Подключение IDE в 1 клик:** автонастройка Cursor, VS Code, Antigravity, Windsurf с режимом маршрутизации через ZCA и напоминанием о фоновом запуске.

## 💡 В планах
- **Air-Gapped режим:** принудительная маршрутизация чувствительных проектов строго на локальные модели (Ollama / vLLM) с блокировкой внешнего сетевого трафика.
- **Zero-Knowledge Context Slicing:** отправка в облако только изолированных интерфейсов без раскрытия полной архитектуры репозитория.
- **Система плагинов:** открытый интерфейс для подключения сторонних провайдеров и кастомных правил DLP.
