## 2. Детализация исправлений

### 2.1. Устранение красного крестика в CI (GitHub Actions)
- **Причина падения:** В Linux-окружении GitHub Actions запуск голого `pytest tests/ -v` не включал текущую директорию репозитория в `sys.path`, из-за чего сборщик тестов падал с ошибкой `ModuleNotFoundError: No module named 'core'`.
- **Решение:**
  1. Создан корневой конфигурационный файл `pytest.ini` с параметрами `pythonpath = .`, `testpaths = tests` и `asyncio_default_fixture_loop_scope = function`.
  2. В шаге пайплайна `.github/workflows/ci.yml` явно задан `PYTHONPATH: .` и вызов переведён на `python -m pytest tests/ -v`.
  3. Добавлен `tests/conftest.py`, который сохраняет снапшот `subscriptions.yaml` и `config.yaml` перед запуском тестов и восстанавливает их по завершении, предотвращая появление «грязных» незакоммиченных изменений на диске.

### 2.2. Лишний .exe в релизе v1.0.0 и унификация названий
- **Причина:** При ручном создании релиза был загружен файл `zero-copy-agent.exe`, а параллельно запущенный workflow сборки `build-desktop.yml` собрал и прикрепил `zero-copy-agent-windows-x64.exe`.
- **Решение:**
  1. Лишний ассет `zero-copy-agent.exe` (ID `773236637`) удалён из релиза через GitHub API.
  2. В релизе оставлены ровно 2 целевых файла:
     - `zero-copy-agent-windows-x64.exe` (Windows x64)
     - `zero-copy-agent-linux-x64` (Linux x64)
  3. Во всей документации (`README.md`, `README_RU.md`, `README_EN.md`, `desktop/README_DESKTOP.md`) ссылки приведены к единому названию `zero-copy-agent-windows-x64.exe`.

### 2.3. Выравнивание версий
- В шапках файлов `README.md`, `README_RU.md` и `README_EN.md` бейдж версии `v0.3.2 Beta` заменён на актуальный стабильный `v1.0.0`:
  `https://img.shields.io/badge/Release-v1.0.0-brightgreen.svg`.

### 2.4. Зачистка вкладки GitHub Actions
- Через GitHub REST API удалены все 13 предыдущих запусков воркфлоу, содержавших упоминания промежуточных коммитов и отладочных веток. Вкладка **Actions** полностью сброшена в чистое состояние.

## 3. Архитектурный аудит модулей

1. **Шлюз (Gateway) — `main.py`, `core/mcp_server.py`:**
   - OpenAI-совместимый API (`/v1/chat/completions`, стриминг SSE, tool-calling).
   - Поддержка нативного протокола MCP (Model Context Protocol) на эндпоинтах `/mcp` и `/sse`.
   - Встроенная раздача статического Web UI на корнях `/` и `/ui`.

2. **Безопасность (DLP Shield) — `core/shield.py`:**
   - Регулярные выражения и энтропийные сканеры для отлова OpenAI, Anthropic, Google, GitHub токенов, приватных ключей SSH/RSA, connection strings и приватных IP-подсетей (`10.x`, `192.168.x`).
   - Изолированное хранилище подстановок `SessionVault` с автоматической демаскировкой ответов.

3. **Сжатие контекста — `core/compression.py`:**
   - Токенизация и эвристическое удаление избыточных пробелов, повторов и комментариев с сохранением синтаксической целостности кода.

4. **Интеграция с редакторами кода — `core/ide_setup.py`, `core/cli_integrate.py`:**
   - Автоматическая настройка в 1 клик для: Google Antigravity, VS Code (Continue), Cursor, Windsurf, Aider, OpenCode.
   - Создание резервных копий конфигов в `~/.zero-copy-agent/backups` перед любым изменением с возможностью отката.

5. **Тестирование — `tests/`:**
   - 66 тестов: аттрибуция моделей, замкнутый аудит-луп, интеграции CLI, сжатие контекста, MCP-протокол, валидация конфигурации (Config Healer), хранилище аналитики и Web UI API.
   - Все тесты изолированы от пользовательских файлов окружения.
