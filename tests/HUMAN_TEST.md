Этот регламент предназначен для быстрой проверки работоспособности шлюза и связки с **Visual Studio Code (расширение Continue)**. Время тестирования: **2–3 минуты**.

## 🔹 Тест 1. Развёртывание и настройка в 1 клик

В окне PowerShell выполните:
```powershell
irm https://raw.githubusercontent.com/solyanni4/zero-copy-agent/main/install.ps1 | iex
```
**Результат:**
1. Проект скачивается и распаковывается.
2. Создается виртуальное окружение `venv`.
3. Устанавливается расширение **Continue** в VS Code.
4. Файл `~/.continue/config.yaml` генерируется автоматически со всеми 3 моделями.
5. Открывается интерактивное меню `start.ps1`.

---

## 🔹 Тест 2. Подключение живой подписки

1. В меню выберите пункт `2` (**Войти в Google Gemini**).
2. В открывшемся окне браузера войдите в аккаунт Google.
3. Нажмите `ENTER` в консоли для фиксации сессии.
4. Выберите пункт `1` (**Запустить сервер**).

---

## 🔹 Тест 3. Проверка генерации и выбора модели в VS Code

1. Откройте VS Code, нажмите **`Ctrl + L`**.
2. В списке моделей выберите **`Gemini Advanced (Zero-Copy)`**.
3. Задайте вопрос:
   > *«Напиши функцию на Python для подсчета чисел Фибоначчи»*
4. **Ожидаемый ответ:**
   ```markdown
   ⚡ **[zero-copy-agent | Gemini Advanced (Живая веб-подписка 🟢)]**

   def fibonacci(n):
       a, b = 0, 1
       ...
   ```
5. Переключите модель в выпадающем списке Continue на **`ChatGPT Plus / GPT-4o (Zero-Copy)`** и повторите запрос.
   Ответ вернется с плашкой соответствующей модели.
